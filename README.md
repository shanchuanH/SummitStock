# Portfolio Risk & Dip-Buy Engine

Packets 01–08 implement the foundation through deterministic ETF Dip, durable jobs, secure session workspace, point-in-time backtests, and deployment acceptance. The system includes user-scoped portfolio intelligence, EOD stops, source-backed theses, event risk, emergency-first allocation, unique manual-only dip tranches, and bias-gated OOS reporting. It never places trades.

## Stack

- JDK 25, Maven Wrapper 3.9.11, Spring Boot 4.1, Spring Modulith 2.1
- MySQL 8.4 LTS, Flyway, JPA/JDBC, Spring Session JDBC
- React 19.2.7, React Router 8.3, Vite 8.1, strict TypeScript, pnpm
- OpenAPI generated by Spring and consumed through a generated TypeScript client

## Local setup

Prerequisites are JDK 25, Node.js 22.22+, pnpm 11+, and Docker Desktop. Copy `.env.example` to `.env` before replacing local-only credentials.

```powershell
docker compose -f infra/compose.yaml up -d mysql
$env:SPRING_PROFILES_ACTIVE = "local-fixture"
$env:PORTFOLIO_PROVIDER_MODE = "fake"
.\mvnw.cmd -pl apps/backend -am spring-boot:run
pnpm dev
```

The API runs at `http://localhost:8080`; the SPA runs at `http://localhost:4173`. The default development login is documented in `.env.example` and must not be used outside local development. The explicit `local-fixture` profile is required for deterministic local providers; omitting it fails closed.

The read-only market inspection page is available at `http://localhost:4173/market-data`. Deterministic fake EOD and SEC/IR adapters are available only under the explicit `local-fixture` and `test` profiles. The default provider mode is disabled, and a non-fixture runtime refuses to start with disabled or fake providers.

Regime, drawdown source, and data-quality gates are shown at `http://localhost:4173/market-context`. Private portfolio drawdown requires authentication; missing snapshots remain explicit `EMPTY` / `WAIT_FOR_DATA` states.

The Dashboard reads one backend-owned contract, `GET /api/v1/brief/today`. The response contains the unified portfolio analysis state, Decimal String summary values, capped action queues, portfolio health, data readiness, upcoming events, strategy version, and evidence time. The browser does not combine multiple APIs to infer readiness.

The authenticated portfolio workspace is available at `http://localhost:4173/portfolio`. It shows summary, positions, and capped Today Actions. Classification and trade-plan controls remain unavailable until they are backed by selected-position, server-side calculations.

Real holdings can be imported at `http://localhost:4173/portfolio-import` from a Fidelity Positions CSV, a copied Fidelity table, or one manually entered holding. Every submission is preview-only until explicit confirmation. Unknown rows must be corrected or ignored; confirmation reconciles the full imported account snapshot, retains history, and queues analysis. SummitStock never connects to or operates a Fidelity account.

Position links open `http://localhost:4173/positions/{positionId}` for server-owned stop, thesis, valuation, earnings, chart-marker, tax, and journal evidence.

The authenticated ETF Dip and cashflow workspace is at `http://localhost:4173/dip-buy`.

Verified backtest reports are at `http://localhost:4173/backtests`. Missing reports render an explicit empty state; offline replay uses completed bars, next-open fills, point-in-time lifecycles, and walk-forward OOS partitions.

API and worker are two runtime modes of the same backend artifact:

```powershell
$env:PORTFOLIO_RUNTIME_MODE = "worker"
.\mvnw.cmd -pl apps/backend -am spring-boot:run
```

The worker persists quote, EOD, weekly, and monthly work before execution. Claims use MySQL leases and `SKIP LOCKED`; retries and attempts are auditable. The web workspace uses same-origin JDBC sessions and CSRF, never browser-stored access tokens, and never sends brokerage orders.

## Verification

```powershell
.\mvnw.cmd spotless:check
.\mvnw.cmd verify
pnpm lint
pnpm typecheck
pnpm test
pnpm build
pnpm api:check
docker compose -f infra/compose.yaml config --quiet
```

OpenAPI is exported from a real Spring context backed by a disposable MySQL 8.4 Testcontainer. Regenerate the contract with `pnpm api:generate` after changing a controller DTO.

## Repository layout

- `apps/backend`: Spring modular monolith and both runtime modes
- `apps/web`: React SPA; display/orchestration only, with no portfolio formulas
- `libs/quant-core`: pure-Java quantitative boundary
- `libs/strategy-core`: pure-Java strategy rules and invariants
- `contracts`: checked-in OpenAPI document and generated TypeScript client
- `db`: reviewed seed inputs; schema changes live under backend Flyway migrations
- `config`: draft, versioned strategy configuration
- `infra`: local Compose and backend image
- `docs`: ADRs, operating notes, and current project state

## Safety boundary

The system is manual-execution only. Unvested compensation is non-liquid and non-tradable. Emergency cash is not deployable capital. “NO URGENT ACTION” may be shown only after the backend explicitly confirms analysis readiness; missing, loading, empty, unauthenticated, and failed states never imply that conclusion.
